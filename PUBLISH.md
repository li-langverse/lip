# Publishing to li-langverse/lip

This repository is infrastructure, not a `lip publish` consumer package.

To create a **user package** under the org, use `li-new-package` from [li-language](https://github.com/li-langverse/li-language):

```bash
./scripts/li-new-package my-lib --official
```

Then push to `github.com/li-langverse/my-lib`.
