# Renovate (optional)

Install the [Renovate GitHub App](https://github.com/apps/renovate) on **`li-langverse`** (all repos or select **lip**, **lit**, **lic**).

This repo’s [`renovate.json`](../renovate.json) bumps `lic_version` / `lit_version` in `li-toolchain.toml` when upstream releases.

Until Renovate is installed, use **`ecosystem-upstream`** issues (label `ecosystem-upstream`) from `lic` release dispatch.
